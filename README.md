​A simple, rule-based Python chatbot designed to process user inputs and respond with predefined messages using basic programming concepts.
​Features
​Interactive Console Chat: Continually accepts user input until an exit keyword is entered.
​Rule-Based Responses: Uses conditional logic to map user greetings and questions to specific answers.
​Case-Insensitive Input Processing: Standardizes user text so inputs like "HELLO", "hello", or "Hello" are treated equally.
​Key Concepts Used
​Loops (while): Keeps the chat loop running until the user says goodbye.
​Conditional Logic (if-elif-else): Evaluates user inputs against predefined rules. 
Input/Output (input(), print()): Reads user entries and displays bot responses.
